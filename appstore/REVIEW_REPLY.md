# レビューへのお詫びの返信

2026年9月13日の星1レビュー「詐欺アプリ。絶対入れるな！！」への、デベロッパからの返信文です。
`▼` の下のコードブロックが、そのまま貼り付ける文面です。

## 返信の出し方

1. App Store Connect → アプリ → 「評価とレビュー」を開く。
2. 該当のレビューの「返信」を押し、文面を貼って送信する。

返信は App Store 上で誰でも読めます。投稿者には通知が届き、返信を見て評価を変更できます。返信はあとから編集できるので、2.0 の公開後に文面 B へ差し替えられます。

## どの文面を使うか

| 時点 | 使う文面 |
|---|---|
| いま（サーバー修正済み、2.0 は公開前） | A |
| 2.0 の公開後 | B（A を出していた場合は編集して差し替える） |

レビューの指摘は3つです。どの文面も、この3つすべてに答えています。

| 指摘 | 事実 |
|---|---|
| 何度やっても「APIフォーマットエラー」で判定できない | そのとおり。利用していたAIモデルの提供終了にアプリが対応できておらず、全員の判定が失敗していた |
| 回数だけ減り、広告を見せられるだけ | そのとおり。回数の消費と広告の表示が、判定の前に行われていた |
| 写真を盗まれていそう | 写真は判定のためにAIへ送信するが、アプリにも中継サーバーにも保存していない。ただし、その説明がアプリ内になかった |

```
このたびは大変ご迷惑をおかけし、誠に申し訳ございません。

ご指摘はすべて事実です。判定が1回もできないまま回数だけが減り、広告だけが表示される状態になっていました。原因は、アプリが利用していたAIモデルの提供が終了したことに、こちらが対応できていなかったことです。完全に当方の不具合であり、長い間気づけなかったことも含めてお詫びいたします。

サーバー側の修正は完了しており、現在は判定できる状態に戻っています。

・回数が減るのは、判定に成功したときだけにします。失敗したときは減りません。
・広告を見て得た回数は、判定に失敗しても残ります。広告を見直さずに再試行できます。
・エラーが起きたときは、何が起きたか・回数がどうなったかを分かる言葉でお伝えします。

写真についてもご不安をおかけしました。選んでいただいた写真は、判定のためにAI（Google の Gemini）へ送信しますが、当アプリにも当方のサーバーにも保存しておりません。この説明がアプリ内になかったことが、ご不安の原因だと受け止めています。2.0 では、最初の判定の前に送信について確認する画面を追加します。

貴重なご指摘をありがとうございました。
```

## 送る前の確認

- **文面 B と短い版は、2.0 が App Store に公開されてから出してください。** 公開前に出すと「修正しました」が事実と合いません。
- **写真の一文について。** 「当アプリにも当方のサーバーにも保存しておりません」はコード上そのとおりです。一方、Google 側での扱いは Gemini API の契約プランによります。無料枠のキーを使っている場合、送信内容が Google のサービス改善に使われる規約になっていることがあります。文面は Google 側の扱いには触れていないので、このままでも事実に反しませんが、課金を有効にしたキーへの切り替えを勧めます（`GOOGLE_ADMOB.md` の7章）。
- **言い訳に読める表現は入れていません。** 「モデルの提供終了」は原因の説明として1回だけ書き、責任はこちらにあると明記しています。
